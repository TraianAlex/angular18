Signal Forms validation demos

Small, copyable examples from the Angular Signal Forms CSS status classes (`ng-invalid`, `ng-valid`, `ng-dirty`) are configured in `app.config.ts`.

Built-in validators, `when`, and custom error objects

`required`, `email`, `minLength`, `min`, `max`, conditional `when`, and replacing the error object with `error`.

Custom `validate` and `validateTree`

No-spaces username, password match (auto-tracks `password`), and a tree rule that reports on last name.

Async HTTP validation and field debounce

`validateHttp` against json-server (`test@test.com` is taken). Search query uses `debounce(path, 300)` so the model lags behind typing.

Disabled, hidden, and readonly

Wholesale disables discount codes. Company name is hidden unless the customer is a business. Total is readonly. Hidden fields are omitted from the template with @if.

Reusable schemas: `apply`, `applyEach`, `applyWhen`, `applyWhenValue`

Shared address/contact schemas, array `applyEach`, card payment `applyWhen`, and invoice `applyWhenValue`.

Zod `validateStandardSchema` (including dynamic schema)

One Zod object drives the form. Strict mode swaps in a longer min-length schema.

Custom controls: `FormValueControl`, `FormCheckboxControl`, `transformedValue`

A text control with automatic error/disabled binding, a checkbox contract, and a money input that parses raw text to a number.

Migration: `compatForm` and `SignalFormControl`

Mix an existing `FormControl` into a signal form, and drop a `SignalFormControl` into a Reactive `FormGroup`.
